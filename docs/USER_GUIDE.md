# User Guide — LinguaBridge AI

Welcome to **LinguaBridge AI**, an intelligent multi-language translation and speech platform.

---

## 1. How to Translate Text

1. **Enter Text**: Type or paste your source text into the left text box (up to 2,000 characters).
2. **Select Source Language**: Choose the input language from the **Source** dropdown menu. You can select **Detect Language** if you do not know the input language.
3. **Select Target Language**: Pick your desired output language from the **Target** dropdown menu (e.g. Hindi, Telugu, Spanish, French, Japanese).
4. **Trigger Translation**:
   - Click the blue **Translate** button, OR
   - Press **`Ctrl + Enter`** on your keyboard while focused on the input box.
5. **View Result**: The translated output will render in the right output panel.

---

## 2. Interactive Features

### ⇄ Swap Languages & Text
Click the **Swap (⇄)** button located between the language dropdowns. This immediately exchanges the source and target language selections and swaps the input text with the translated output.
*(Note: Swap is disabled when the source language is set to "Detect Language").*

### 🔊 Text-to-Speech (TTS)
- Click the **Speaker (🔊)** icon below either text box to listen to the text read aloud using native browser speech synthesis.

### 📋 One-Click Copy
- Click the **Copy (📋)** icon on the output panel to copy the translated text directly to your system clipboard. A toast notification will confirm "Copied!".

### 💾 Download as TXT File
- Click the **Download (💾)** icon on the output panel to instantly export and download the translation as a `.txt` document (`translation.txt`).

### 🌓 Dark / Light Theme
- Click the **Moon / Sun** icon in the header navigation bar to toggle between Light Mode and Dark Mode. Your theme selection is automatically remembered.

---

## 3. Translation History & Dashboard

- **Session & Saved History**: Every successful translation is saved to the **Recent Translations** panel.
- **Search History**: Use the search bar in the History section to filter previous translations by keyword.
- **Clear History**: Click **Clear History** to purge stored translation items.
- **Analytics Dashboard**: Registered users can access the **Dashboard** page to view translation usage metrics, character counts, and top language pairs.
